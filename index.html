INTERPRETATIONQ0(b) — Purpose of scale()

The command scale(data) performs Z-score standardisation (also called mean-centering and unit-variance scaling) on every column of the data frame. For each variable X, it computes:

Z = (X − mean(X)) / sd(X)

After scaling, every variable in data_scaled has a mean of 0 and a standard deviation of 1. This is essential for multivariate analyses such as PCA, FA, CCA, and clustering because:

  • Variables measured in very different units (e.g., income_per_capita in tens of thousands vs. inflation in single digits) would otherwise dominate the analysis based on their scale rather than their statistical relationships.
  • Standardisation ensures that each variable contributes equally to distances, covariances, and variance decomposition.
  • The resulting matrix is equivalent to working with the correlation matrix rather than the raw covariance matrix.

INTERPRETATIONQ2(a) — KMO & Bartlett Tests

KMO Test (Kaiser-Meyer-Olkin Measure of Sampling Adequacy):

  • The Overall MSA (Mean Sampling Adequacy) = 0.74, which falls in the "middling to meritorious" range by Kaiser's guidelines (0.6 = mediocre, 0.7 = middling, 0.8 = meritorious, 0.9 = marvelous).
  • Individual variable MSA values range from approximately 0.68 to 0.79, all above the minimum threshold of 0.5.
  • Conclusion: The correlation matrix has sufficient shared variance among variables to proceed with Factor Analysis. The data is factorable.

Bartlett's Test of Sphericity:

  • H₀ (null hypothesis): The population correlation matrix is an identity matrix (all off-diagonal correlations = 0).
  • Result: χ² = 3419.54, df = 120, p-value ≈ 2.34 × 10⁻⁴⁸⁷ (essentially zero).
  • Conclusion: We strongly reject H₀. The variables are significantly inter-correlated, which means the correlation matrix is far from an identity matrix. Factor Analysis is statistically justified — there are meaningful latent factors driving the observed correlations.

Both tests together confirm that the data is well-suited for Factor Analysis.

SUMMARY Integrating PCA · FA · CCA · K-Means across all 16 variables

This assignment applied four major multivariate techniques to a synthetically generated dataset of 300 observations and 16 socio-economic variables derived from 5 latent factors. The results from each method converge into a coherent picture:

1. Principal Component Analysis (PCA)

PCA reduced 16 variables to 5 principal components explaining 81.0% of total variance. The scree plot showed a clear elbow after PC5, and the Kaiser criterion confirmed 5 eigenvalues above 1.0. Each PC mapped onto a distinct domain: PC1 ↔ Education, PC2 ↔ Economic, PC3 ↔ Health, PC4 ↔ Social, PC5 ↔ Environmental. 2. Factor Analysis (FA)

Both KMO (MSA = 0.74) and Bartlett's test (χ² = 3419.54, p ≈ 0) confirmed the data is suitable for FA. Varimax-rotated FA with 5 factors (Nfacs = 5) produced a near-perfect simple structure — each variable loaded strongly (≥ 0.77) on exactly one factor and negligibly on all others. The five factors were named: Education Factor (ML1), Economic Prosperity Factor (ML2), Health Factor (ML3), Social Environment Factor (ML4), and Environmental Quality Factor (ML5). Communalities ranged from 0.62 to 0.87, confirming excellent model fit.

3. Canonical Correlation Analysis (CCA)

CCA revealed 3 statistically significant dimensions of association between the Economic-Social variable set (X) and the Health-Education-Environmental variable set (Y).
